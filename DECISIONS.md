# Décisions d'architecture

Chaque décision en trois lignes : contexte, choix, alternative écartée.
Statut : **proposée** (en attente de validation) ou **validée**.

## D-001 — Dépôt et suivi du cadrage (validée)

- Contexte : le cahier des charges est fourni en prompt ; le conteneur de travail est éphémère.
- Choix : `SPEC.md` à la racine fait foi ; réponses de l'étape 0 consignées dans `docs/cadrage/reponses.md`, note finale dans `docs/cadrage/note.md`.
- Écarté : garder la spec hors dépôt (perdue entre deux sessions).
